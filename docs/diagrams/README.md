# Схема базы данных

Открыть [database.html](database.html) в браузере: масштабирование, перемещение,
выбор таблицы с подсветкой связей и просмотром ключей/индексов.

Генерация из последнего числового экспорта Room:

```sh
python3 docs/diagrams/build_database_diagram.py
```

Шаблон — database.template.html. Частичный индекс цветов уточняется генератором:
условие WHERE isCompleted = 0 задаётся в миграции и onCreate, поскольку Room-аннотация
не поддерживает частичные индексы. Остальные поля/ключи читаются из экспорта схемы.
