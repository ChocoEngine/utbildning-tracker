## Ограничения демонстрации

Все данные локальные. HTML не проверяет Room, Android lifecycle, IME, уведомления,
часовой пояс/DST, долговечность записи или отказ backend. Даты фиксированы:
26 сентября 2026 — «сегодня», 25 сентября — «вчера».
Макеты RU, переключения EN нет; EN не проверен.
Тёмная тема части старых макетов остаётся демонстрационной и не считается принятой.

Встроенная форма courses показывает создание и отдельное сохранение полей;
темы/расписание доступны независимо в упрощённых окнах. Полный независимый редактор — course-editor. Макеты не имеют общей БД.
Receipt после результата — локальная обратная связь демонстрации; приложение
возвращает пользователя к предыдущему экрану. Read-only варианты результата и вчерашнее занятие выбираются внешним
переключателем «Дата занятия (пример)»; это управление фикстурой, не функция приложения.
В schedule-overlaps используются фиксированные активные курсы без конечных дат:
это примеры геометрии интервалов, а не полная модель отбора repository.

## Проверки

Chrome 154.0.8037.98 через Playwright, реальные штатные экспортированные
документы с sandboxed iframe; светлая тема. Размеры — viewport браузера в CSS px,
с внешней обёрткой, а не новые измерения Android в dp.

- Восемь исходников: inline JavaScript проверен `node --check`.
- Восемь экспортов получены `render.py` visualize 1.0.47; каждый побайтно совпал
  с повторным `render(source)` штатного экспортёра. Сгенерированные HTML вручную не правились.
- 12 групп переходов/действий в [verify.cjs](verify.cjs): создание/отмена без режима,
  независимые темы/расписание, поля, палитра/категория, удержание клавишей,
  применение/отмена/конфликт/100 Unicode code points, номера, пауза/продолжение/
  повторная пауза/завершение без выхода, вчерашний PENDING, оба результата и
  снятие выбранного, обычный выбор тем, календарь без записи, ночной конец,
  отмена/удаление конца, только дата и отключение, восемь примеров пересечений,
  today/yesterday/older/future/completed на экране результата.
- Дополнительно [verify-extra.cjs](verify-extra.cjs): удержание мышью по названию
  и теме, доступность подтверждения удаления категории, отмена редактора тем,
  сохранение уже пройденного количества в упрощённой форме courses.
- Прокрутка списка курсов не сдвигает сводку; списки тем и дней доступны
  прокруткой. У Today два самостоятельных scroll-контейнера. Сравнена геометрия
  блока редактора: список тем имеет ненулевую доступную высоту на обоих размерах.
- Все восемь экранов открыты при 320 × 540 и 411 × 914; сохранены и просмотрены
  16 базовых снимков и восемь дополнительных состояний. Горизонтального
  переполнения body нет. Снимки светлой RU-демонстрации; EN отсутствует.
- `pageerror` и ошибки console: 0. Фактические результаты —
  [browser-results.json](browser-results.json), [browser-extra.json](browser-extra.json).
- Относительные ссылки обновлённых Markdown ведут на существующие файлы;
  `git diff --check` прошёл. Первоначальный tracked diff QA-001 совпал побайтно
  после работы; посторонние файлы не правились.

Браузер выявил и позволил исправить локальные проблемы HTML: нативный submit
запрещён штатным sandbox, поэтому действия форм выполняются кнопками без
отправки; длинные действия вытесняли темы, а относительная высота панели примеров
вызывала уменьшение iframe; статус паузы накладывался на категорию, подтверждение
удаления категории оказывалось за её окном. Эти исправления затрагивают только
макеты и не являются изменениями Android-приложения.
