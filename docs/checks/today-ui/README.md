## Переключаемые отметки

На «Сегодня» убраны вопрос, подпись состояния справа и действие «Без отметки». Выбранная кнопка темнее на 10% цвета текста, остальные сохраняют светлую подложку. Повторное нажатие выбранного действия вызывает существующее сохранение PENDING. «Пропущено» переключает DONE → SKIPPED и снимает прохождение тем данного занятия; «Пройдено» из PENDING/SKIPPED открывает выбор тем и фиксируется по «Сохранить». Назад из выбора ничего не записывает.

Снятие DONE использует действующую транзакцию репозитория: удаляются только прохождения с source=SESSION и sessionId этого занятия. Исторические связи остаются; независимые ручные отметки и отметки других занятий не меняются. Для уже завершённого курса действующие правила сохраняют прохождение, принадлежащее завершению курса.

Выполнены assembleDebug (BUILD SUCCESSFUL) и обновление APK с сохранением БД. Тесты не запускались. [Текущий снимок](today_toggle_buttons.png).
