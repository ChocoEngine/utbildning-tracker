# Темы за занятие — 2026-10-04

В списке курсов после счётчика тем показан целочисленный темп с округлением вверх:
«5 из 24 тем · 3 темы за занятие» / `5 of 24 topics · 3 topics per session`.
Минимум — 1; при полном прогрессе подпись исчезает без «Все пройдено».
Для паузы, завершения, отсутствия даты/правил/оставшихся занятий темп скрыт.
Контракт расчёта: [SCHEDULE_CONTRACT.md](../../SCHEDULE_CONTRACT.md).

## Проверки

- JDK 17: `./gradlew :app:assembleDebug :app:lintDebug :app:testDebugUnitTest :app:assembleDebugAndroidTest --console=plain` — успешно.
- `TopicPaceTest`: 4 теста — округление, минимум, пустые случаи, включительные границы, исключение результатов, сравнение с генератором на 401 диапазоне до 400 дней.
- API 36: `CourseTopicPaceTest` (2 RU/EN), `TopicPaceRepositoryTest` (1), два целевых метода `CourseListAppearanceTest` — **5/5**.
- Тесты RU/EN на 320 dp проверяют строки, отсутствие темпа при полном прогрессе и границы текста относительно колонки процента. Снимки: [RU](screenshots/ru.png), [EN](screenshots/en.png).
- Репозиторный тест проверяет сегодняшнее PENDING, пропуск, ручное прохождение темы, изменение конечной даты и её удаление. База теста — отдельная in-memory Room.
- APK установлен поверх прежнего на API 36, без очистки данных. Коммита и push нет.

Первый UI-прогон выявил ошибку измерения в тесте: объединённая семантика кликабельной строки давала границы всего ряда. После перехода к границам отдельных Text оба языковых теста прошли.
