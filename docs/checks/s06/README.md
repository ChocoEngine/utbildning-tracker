# S06: редактирование списка тем — 2026-09-26

Реализованы чистые правила `domain/TopicListEditor.kt` и транзакционное
сохранение `TrackerRepository.saveTopicList`. До реализации зафиксирован
[контракт](../../DATA_CONTRACT.md): исходные номера строк, точное FIFO
сопоставление повторов, сохранение ID, архивирование удалённых строк.
Пройденные темы, отметки и история сохраняются неизменными.
Черновик не пишет в БД; сохранение повторно проверяет актуальное прохождение.

Реализация и тесты подготовлены параллельно субагентами; основной агент
проверил код и выполнил общий прогон.
