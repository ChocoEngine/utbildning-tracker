# Упрощение прохождения тем — 2026-09-27

Выполнено по [заданию](../../TOPIC_COMPLETION_SIMPLIFICATION_PROMPT.md).

Room v4 хранит прохождение непосредственно в `topics.isCompleted` и
`topics.completionDate`. Дата — локальный epoch day занятия; ручная отметка
и прохождение оставшихся тем при завершении курса используют null.
Удалены сущности, DAO и потребители `topic_completions` / `session_topic_history`.
Старые таблицы упоминаются только в миграциях и их тестовых данных.

Миграция 3→4 сначала переносит актуальные отметки, затем удаляет старые таблицы
в порядке зависимостей. SESSION получает дату занятия; MANUAL и
COURSE_COMPLETION — null. История без актуальной отметки не восстанавливает
прохождение. Проверены архивные темы, категории, резерв цвета, расписание,
результат занятия, порядок тем и отсутствие нарушений внешних ключей.
Проверены переходы 3→4 и всей цепочки 1→2→3→4 по настоящим файлам SQLite.
Экспортирована схема 4.json, обновлены контракт данных, расписания, RU/EN гайд
и HTML-схема БД.

Изменять результат пользователь может только для сегодняшней даты по часовому
поясу репозитория. На экране других дат нет сохранения, выбор отключён.
Сброс и изменение выбора снимают только текущие отметки данного курса за дату
занятия; ручные отметки и другие даты сохраняются. Повторная запись идемпотентна.
Просмотр и автоматическая обработка прошлых PENDING сохранены. Генерация
не добавляет второе занятие курса на уже занятую дату. Существующие занятия
не удаляются ради нового ограничения.
