# F15 — настройка срока хранения

Дата проверки: 2026-10-07.

## Принятый контракт

- По умолчанию сохраняются сегодня и предыдущие 365 локальных календарных дней.
- Допустимое значение — от 1 до 3650 предыдущих дней включительно.
- Очистку можно полностью отключить; тогда границы удаления нет.
- Для значения `N` граница равна `today - N` в актуальном часовом поясе. Занятие на границе сохраняется, удаляются только занятия с более ранней локальной датой начала.
- Правило не принимает состояние курса или время его изменения и потому одинаково для всех курсов.
- Уменьшение срока, включая включение очистки после отключения, требует отдельного подтверждения о том, что ближайшая очистка удалит больше старых записей. Увеличение срока и отключение сохраняются без разрушительного предупреждения.

Настройка хранится в отдельных `SharedPreferences` и переживает пересоздание Activity и полный перезапуск приложения. Некорректное сохранённое значение безопасно заменяется значением по умолчанию. Тексты настроек и гайда добавлены на русском и английском.

## Реализация

- `maintenance/RetentionSettings.kt` задаёт диапазон, постоянное хранение, вычисление границы и предикат удаления.
- `ui/settings/SettingsScreen.kt` показывает текущее значение, редактор, выключатель, ошибку диапазона и подтверждение уменьшения.
- F15 не удаляет занятия и не запускает фоновую работу: транзакционная операция и ежедневный WorkManager относятся к F16.

## Проверки

- `./gradlew testDebugUnitTest` — успешно, 36/36 JVM-тестов. Новые тесты проверяют точную границу, отключение и пересчёт локального дня для UTC, Europe/Moscow и America/Los_Angeles.
- `./gradlew assembleDebug assembleDebugAndroidTest lintDebug` — успешно.
- Отдельный API 36 AVD `ScheduleReturnFix`, без очистки данных, после повторяемого заполнения: `RetentionSettingsTest` — 2/2 и направленный RU/EN-тест гайда — 1/1. Проверены значение по умолчанию, ошибочный ввод, уменьшение с предупреждением, увеличение без предупреждения, полное отключение, повторное включение, RU/EN-контракт и холодный перезапуск приложения. После удлинения настроек языковой тест явно прокручивает к выбору языка.
- Настройки и окно редактирования просмотрены вручную на 320 × 540 dp в английской локали; обрезки действий и полей нет.

## Ограничения

- Само удаление и периодический запуск не проверялись и не реализованы в F15; это критерии F16.
- Полный instrumentation-набор и Android 13 не запускались.
- Отдельный ручной визуальный просмотр русской локали не выполнялся; русские ресурсы проверены направленным API 36 тестом.
