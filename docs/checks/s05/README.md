# S05: курсы, категории, цвета и лимит — 2026-09-26

Добавлен `data/TrackerRepository.kt`; DAO расширен запросами категорий,
резервов и количества незавершённых курсов. Создание курса с начальными темами,
выбор/создание категории и резервирование цвета — одна Room-транзакция.
Редактирование меняет резерв атомарно, не затрагивая историю занятий.
Режим задаётся только при создании. Правила API описаны в
[контракте данных](../../DATA_CONTRACT.md).

Реализация и инструментальные тесты подготовлены параллельно, выполнено
независимое ревью. Схема БД остаётся v1; зависимости, включая AGP 8.13.2,
не обновлялись.

## Проверка

Окружение: JDK 17.0.13, macOS arm64, `Medium_Phone_API_36`, Android 16.
Из `tracker-app/` с окружением из README:

```sh
./gradlew :app:assembleDebug :app:lintDebug :app:connectedDebugAndroidTest --console=plain
```

Итог: **BUILD SUCCESSFUL, 28 тестов, 0 ошибок, 0 пропусков**.
Lint: 0 ошибок / 14 прежних предупреждений (12 об обновлениях зависимостей,
иконка и dataExtractionRules). SHA-256 экспортированной схемы до/после сборки
совпадает: `7ae92d1e47f095454af1a6b56e2e3b7f06010db264de27cf2cbc27c6a88f349b`.

11 новых инструментальных тестов в `data/TrackerRepositoryTest.kt` проверяют:

1. Создание курса и начальных тем без фиктивного календаря.
2. Ошибки названия, цвета и списка тем без частичных записей.
3. Точное сопоставление категорий с кириллицей, регистром и пробелами;
   смена/очистка категории не затрагивает другой курс.
4. Явное переименование общей категории и запрет конфликтующего имени.
5. Десять незавершённых курсов, включая паузу и режим без расписания;
   одиннадцатый отвергается, завершённые не учитываются, редактирование разрешено.
6. Неудачное редактирование сохраняет имя, категорию и резерв цвета.
7. Смена цвета освобождает прежний резерв; режим, темы, прогресс и снимки
   исторического занятия сохраняются.
8. Завершённый курс хранит прежний цвет, который доступен новому курсу.
9. Два экземпляра репозитория конкурируют за один цвет: сохраняется один курс.
10. Одновременное сохранение курсов с одинаковой категорией создаёт одну категорию.
11. Поздняя ошибка SQLite при вставке темы откатывает уже созданные категорию,
    курс и резерв цвета; существующие данные сохраняются.

В общий прогон также вошли прежние 9 Room-тестов и 8 UI-тестов.

## Ограничения

S05 добавляет API, а не формы курсов. Отмена формы проверяется в S07;
до вызова сохранения репозиторий не создаёт категории. Разбор текстового
списка и редактирование существующих тем — S06. Завершение, пауза и удаление
курса — S18. Эти состояния в тестах S05 задаются напрямую через DAO для
проверки лимита и цветов. Генератор календаря ещё не подключён.

Новых экранов нет, существующие Preview сохранены. Android 13 отложен
пользователем; проверка на API 36 его не заменяет.
