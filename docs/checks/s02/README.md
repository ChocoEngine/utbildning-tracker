# Проверка S02 — 2026-09-26

Выполнены общая светлая тема, палитра 10 курсов, три пустых основных экрана
и отдельные настройки с возвратом. Тема и навигация реализованы параллельно
двумя субагентами, затем объединены и проверены. Бизнес-данных пока нет.

Окружение: macOS arm64, JDK 17.0.13, AVD `Medium_Phone_API_36`, Android 16.
Проверка на Android 13 явно отложена пользователем.

Из `tracker-app/`, после задания JAVA_HOME и ANDROID_HOME по README:

```sh
./gradlew :app:assembleDebug :app:lintDebug :app:connectedDebugAndroidTest --console=plain
```

Результат: **BUILD SUCCESSFUL**, 3 теста, 0 ошибок и пропусков:

- Переходы по всем трём вкладкам, настройки из каждой вкладки, возврат
  кнопкой шапки и через системный Back dispatcher.
- Повторные нажатия на вкладку не создают ловушку возврата; пересоздание
  Activity сохраняет настройки и исходную вкладку; Back с вкладки ведёт
  на «Сегодня».
- Длинный русский заголовок при ширине 320 dp и fontScale 2 не пересекает
  кнопку настроек, кнопка остаётся видимой и нажимается.

В первом прогоне тест вызывал Back до завершения перехода. Добавлено ожидание
готовности Compose перед Back; итоговый прогон выше прошёл полностью.

Lint: 0 ошибок, 11 предупреждений. Девять о доступных обновлениях закреплённых
версий; два сохранённых предупреждения S01 — отсутствующая иконка приложения
и явные правила `dataExtractionRules`. Предупреждения не подавлены.

## Визуальная проверка

После инструментальных тестов APK установлен отдельно через `adb install -r`.
Холодный запуск `adb shell am start -W -n com.utbildning.tracker/.MainActivity`
завершился `Status: ok`. Локали переключались средствами эмулятора:

```sh
adb shell cmd locale set-app-locales com.utbildning.tracker --locales ru
adb shell cmd locale set-app-locales com.utbildning.tracker --locales en
```

Проверены [русский](ru.png) и [английский](en.png) экраны: подписи и иконки
помещаются, нижняя панель отделена от системной области. При тёмном системном
режиме приложение сохраняет светлую тему и тёмные системные значки.
После проверки принудительная локаль сброшена, night mode возвращён в auto.
Внутреннего выбора языка ещё нет — это S03.

Источники стиля: `design/mockups/sources/courses.html`, `calendar.html`,
`design/mockups/PALETTE.md`. Используются встроенные Serif/SansSerif, без
загрузки шрифтов. Сохранённые HTML-прототипы не изменены.

Границы проверки: Android 13, физический телефон и бизнес-функции не проверены.
Полный экран «Сегодня» с датой и занятиями будет реализован в S17; здесь
пока заголовок пустого раздела.
