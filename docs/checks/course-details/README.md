# Экран курса — 2026-09-27

Реализовано по course-details.html с уточнением пользователя: палитра в отдельном окне. Галочки тем и выбранного цвета используют прежний ic_check. Цвет справа от названия; статус под ним; категория открывает окно ввода/поиска с прежним удалением категорий. Темы прокручиваются отдельно. Расписание над темами и действия снизу закреплены. Завершённый курс не показывает расписание. «Продолжить» снимает паузу без формы и расписания, сохраняя темы, прогресс и цвет. Общий CourseActionButton задаёт #718376 / #FCFAF6 и 13 dp для добавления и действий.

На маленьком экране название ограничено тремя строками с многоточием, полное значение сохраняется и доступно при редактировании. Проверки состояния: 0 — активный с расписанием и конечной датой, 1 — пауза, 2 — завершённый, 3 — активный без расписания. Снимки RU/EN при 320 × 540 dp приложены; expanded показывает отдельное окно палитры.

Проверки: assembleDebug, assembleDebugAndroidTest, lintDebug — BUILD SUCCESSFUL. testDebugUnitTest — 15/15. Через adb instrumentation CourseDetailsReviewTest — 3/3 на API 36: RU/EN, состояния, выбор/закрытие палитры, неизменность положения действий после прокрутки, сохранность тем/прогресса/цвета при снятии паузы. Повторяемое заполнение — 2/2. APK установлен с сохранением данных.

Контраст заданных цветов рассчитан: 3.87:1. Визуально подписи различимы, но это ниже 4.5:1 для мелкого текста; цвета оставлены по явному требованию. Макет HTML оставлен без изменений.

Последующее уточнение: расписание перенесено над заголовком «Темы», после категории. Снимки обновлены после переноса расписания вверх и изменения разделителей.
