## Результат и границы

Подготовлены новые тексты именно для раздела «Как пользоваться» внутри приложения:
[русский](../../guide/ru.md) и [английский](../../guide/en.md).
Пользователь уточнил объём: сначала Markdown для просмотра, перенос в приложение
позже. Тексты не являются техническим README и не содержат инструкций разработчику.

Сначала идут создание курса, темы, расписание и отметка занятия. Далее — календарь,
напоминания, действия с курсом, ручные и еженедельные копии, восстановление и очистка.
Списки шагов показывают, куда нажать, и что получится. Редкие ограничения вынесены
в конец. Предупреждения о перезапуске, удалении, полной замене при восстановлении,
незашифрованных файлах и очистке выделены цитатными блоками Markdown.
RU/EN имеют одинаковые 13 разделов и одинаковые существенные условия.

## Сверка с реализацией

Тексты проверены по `GuideScreen.kt`, текущим RU/EN `guide_strings.xml`,
`course_strings.xml`, `schedule_strings.xml`, `session_strings.xml`, `strings.xml`,
а также `CoursesScreen.kt`, `CoursesViewModel.kt`, `ScheduleScreen.kt`,
`TodayScreen.kt`, `SessionScreen.kt`, `SessionRows.kt`, `CalendarScreen.kt`,
`SettingsScreen.kt`, `TrackerOperations.kt`, `SessionEditPolicy.kt`,
`RetentionSettings.kt`, `BackupModels.kt` и контракту резервных копий.

Уточнения по сравнению со старым гайдом:

- Расписание открывает значок календаря; у курса на паузе сначала «Продолжить».
- Названия действий совпадают с ресурсами: «Далее», «Применить список»,
  «Восстановление», «Заменить и восстановить» и их английские варианты.
- Календарь показывает результаты; изменение выполняется в «Занятиях».
- Для изменения результата учитывается дата начала сегодня / вчера;
  завершённые курсы доступны только для просмотра.
- Отмена «Пройдено» снимает связанные с этим занятием отметки тем.
- Завершение отмечает оставшиеся темы и начавшиеся занятия без результата;
  перезапуск удаляет прохождение и всю прежнюю историю курса.
- Копия содержит данные и язык; на другом телефоне нужно снова выбрать папку
  еженедельных копий и проверить разрешения.
- Очистка сохраняет граничный день и прогресс тем. Точное время фоновых копий
  и очистки не обещается. Отменённый перенос занятий не описывается.

Проверены параллельность содержания RU/EN, структура Markdown, названия действий
и отсутствие технических подробностей в пользовательском тексте.
Проверка пробелов: `git diff --check`; для новых файлов —
`git diff --no-index --check /dev/null <файл>`.
