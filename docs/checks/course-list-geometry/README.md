# Проверка названия и процента в списке курсов — R01-003

Дата: 2026-10-05. **Воспроизводимого дефекта отображения не обнаружено; текущую разметку сохраняем.** Предыдущее структурное замечание об общей границе колонок не требует изменения UI по итогам уточнения пользователя и проверки.

## Окружение и объём

Отдельный временный AVD API 36 `ListReview`, serial `emulator-5556`, экран 640 × 1240 px при density 320 (320 × 620 dp), стандартный масштаб текста. Пользовательский AVD не запускался и не изменялся. Повторяемое демо-заполнение на тестовом устройстве прошло: `OK (1 test)`.

Проверяется реальный `CourseListContent` текущей сборки в Compose TestActivity с локальными фикстурами без изменения БД. Проверка не заменяет приёмку всего приложения. Названия: 50 символов с пробелами, 50 `W` без пробелов и старое длинное имя (RU 174 / EN 165 символов). Проценты: 9/10/99/100%, RU/EN. Правый край процента сравнивается с тем же курсом при коротком имени.

## Результат

- Все восемь сочетаний языка и процента: имя переносится, `TextLayoutResult.hasVisualOverflow = false`.
- Названия занимают 2–3 строки для 50 символов и 6–7 строк для старых длинных имён.
- Название находится над строкой процента, пересечения нет: зазор 8 px (4 dp).
- Правый край процентов остаётся x = 544 px и совпадает с короткими названиями; длина названия его не сдвигает.
- При прокрутке длинных строк весь текст доступен. Снимки просмотрены визуально.

Общая горизонтальная граница названия перед процентом отсутствует, поскольку процент находится ниже названия. Это само по себе не вызывает наложение или обрезку. Исходники приложения для этой проверки не менялись; добавлен воспроизводимый проверочный тест `CourseListGeometryReviewTest`.

## Команды и проверки

Из `tracker-app/`, JDK 17 и Android SDK из README:

```sh
./gradlew :app:assembleDebug :app:assembleDebugAndroidTest --console=plain
adb -s emulator-5556 shell am instrument -w -e timeout_msec 120000 -e class com.utbildning.tracker.ui.CourseListGeometryReviewTest,com.utbildning.tracker.ui.CourseListAppearanceTest com.utbildning.tracker.test/androidx.test.runner.AndroidJUnitRunner
```

Сборка: `BUILD SUCCESSFUL`. Целевой запуск: `OK (6 tests)`. После замены четвёртого названия фикстуры на обычный пример курса по C тестовый APK пересобран, два геометрических теста повторены: `OK (2 tests)`.

Полный instrumentation, lint и JVM в этой проверке не запускались: бизнес-логика и исходники приложения не менялись. Android 13, крупный шрифт и S25 не проверялись. R02 целиком не закрывается.
