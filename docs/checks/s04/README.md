# S04: модель данных и Room — 2026-09-26

До реализации зафиксирован [контракт данных](../../DATA_CONTRACT.md):
сущности, единицы хранения времени, отдельные текущие отметки и исторические
связи, таблица будущих переходов результата. Контракт и код прошли независимое
ревью; сущности/DAO и тесты реализованы параллельно.

Добавлены Room 2.8.4 и KSP 2.3.6. Остальные закреплённые версии не менялись.
Настройка соответствует [документации Room](https://developer.android.com/jetpack/androidx/releases/room)
и [KSP](https://kotlinlang.org/docs/ksp-quickstart.html).

В `tracker-app/app/src/main/java/com/utbildning/tracker/data/local/`:

- 9 сущностей, enum-состояния и проверки значений конструкторов.
- Составные FK для принадлежности темы/занятия одному курсу, уникальные
  ключи занятий и резервов цветов, каскады удаления, SET NULL категории.
- TrackerDao: suspend-операции хранения и Flow для наблюдения; вставки ABORT,
  без REPLACE и без прямого подключения DAO к UI.
- TrackerDatabase: файловое открытие через applicationContext, версия 1,
  без destructive migrations. Экспортированная схема:
  `tracker-app/app/schemas/com.utbildning.tracker.data.local.TrackerDatabase/1.json`.

## Проверка

Окружение: JDK 17.0.13, macOS arm64, `Medium_Phone_API_36`, Android 16.
Из `tracker-app/` с окружением из README:

```sh
./gradlew :app:assembleDebug :app:lintDebug :app:connectedDebugAndroidTest --console=plain
```

Итоговый общий прогон: **BUILD SUCCESSFUL, 17 тестов, 0 ошибок, 0 пропусков**.
Lint: 0 ошибок / 14 предупреждений — 12 о новых версиях зависимостей и
2 прежних об иконке/dataExtractionRules. Новых ошибок схемы или Room нет.

В `TrackerDatabaseTest` добавлены 9 инструментальных тестов:

1. Диапазоны цвета, дня, времени и согласованность источника отметки.
2. Ручная отметка без фиктивных занятий/расписания.
3. Несуществующие родители, связи между курсами и SESSION без исторического факта отвергаются SQLite.
4. Дубли ключей не заменяют существующие данные, в том числе резервы цветов.
5. Удаление категории/расписания сохраняет курс, занятия и историю.
6. Удаление курса очищает его зависимые записи и не затрагивает другой курс.
7. Снятие текущей отметки и изменение/архивирование темы сохраняют исторический факт и DONE.
8. Ошибка внутри Room-транзакции откатывает уже выполненные вставки.
9. Файловая БД после закрытия и повторного открытия сохраняет ручной источник,
   независимую историю, расписание и разные состояния DONE/PENDING/SKIPPED.

Это тесты хранения, а не реализация будущих бизнес-операций S05/S08/S13.
Предшествующие 8 UI-тестов входят в общий прогон.

После перезапуска сервера первый общий прогон оборвался: logcat фиксировал
удаление пакета приложения во время теста, без исключения SQLite. Отдельный
последовательный прогон всех 9 Room-тестов завершился BUILD SUCCESSFUL.

## Ограничения

БД пока не подключена к экранным бизнес-операциям; репозиторий начинается в S05.
Лимит курсов, согласованность резерва со статусом и транзакции исправления
результата ещё не реализованы. Проверки конструкторов не заменяют SQL CHECK
для произвольного raw SQL. DAO возвращает также архивные темы — UI/прогресс
в будущих шагах должны исключать их.

Android 13 отложен пользователем. Миграций ещё нет: это первая схема.
Проверено переоткрытие реального файла БД, а не перезагрузка телефона.
Новых экранов в S04 нет; существующие Preview сохранены.
