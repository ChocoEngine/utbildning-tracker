# Отказ и повтор автосохранения — 2026-10-06

Подтверждённых дефектов в проверенных сценариях не найдено. Код приложения не
изменялся. Добавлены три регрессии в `CoursesScreenTest` с настоящим отказом

После удаления trigger повтор выполняется на той же открытой базе и ViewModel.
Все базы этих тестов in-memory и изолированы от данных приложения.

## Проверенные сценарии

- Имя, категория и цвет: ошибка STORAGE отображается в редакторе; последнее
  успешное значение курса в Room не меняется; введённое значение остаётся в
  draft; повтор сохраняет его и убирает ошибку.
- Категория: отказ обновления курса откатывает также создание новой категории;
  частично созданная категория не остаётся в базе.
- Фон, открытие расписания и выход: при ошибке черновик сохраняется, callback
  перехода/выхода не вызывается. Повтор успешно записывает поля; выход очищает
  draft только после успешной записи. Неприменённый текст тем не сохраняется.
- Быстрая очередь имени, категории, цвета и выхода: в Room остаются последние
  значения всех полей; пробелы и регистр не создают дубль категории; черновик
  тем не применяется.

Новые сценарии вызывают команды ViewModel в работающем Compose-экране и проверяют
Room, draft, ошибку в semantics и callbacks. Реальный Home и пересоздание Activity
проверяются существующим `CourseDraftRecreationTest` для успешной записи. Отказ
во время уничтожения процесса, физическая нехватка места и RU/EN-визуальная
приёмка ошибки в этой задаче не проверялись. Окно категории/IME (UI-C01) не
входит в объём.
