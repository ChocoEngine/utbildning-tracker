# S03: выбор языка и Preview — 2026-09-26

В настройках доступны «Как в системе», «Русский», «English».
Единственный источник сохранённого выбора — `LocaleManager.applicationLocales`
Android 13+: пустой список означает системный язык, `ru` и `en` — явный выбор.
Собственного хранилища или изменения глобальной локали процесса нет.
Выбор согласован с системными настройками языка приложения.

Список поддерживаемых языков объявлен в `res/xml/locales_config.xml` и manifest.
`androidResources.localeFilters` исключает неподдерживаемые переводы зависимостей.
Ресурсы по умолчанию — английские, `values-ru` — русские.
Подход основан на [официальном API языка приложения](https://developer.android.com/guide/topics/resources/app-languages)
и [LocaleManager](https://developer.android.com/reference/android/app/LocaleManager).

UI хранит только снимок выбора: перечитывает системное значение после нажатия,
при изменении конфигурации и возвращении на экран. Это учитывает изменение
настройки без изменения фактического языка (например, системный английский
и явно выбранный английский). Навигация сохраняется при пересоздании Activity.
