# Упрощение модели данных — 2026-09-27

Реализованы согласованные замечания: удалены archivedAt, endDayOffset,
generationNotBefore, mode, completionPromptDismissed и color_reservations.
Равные времена означают нулевую длительность. Генерация новых занятий не создаёт
прошедшие начала; догоняющая обработка сохраняет ранее созданные записи.
Синхронизация запускается при входе/возврате и на местной границе суток.
Темы и расписание необязательны, настройка расписания возобновляет паузу.
Цвета заняты незавершёнными курсами через частичный уникальный индекс;
завершение сбрасывает цвет и запрещает редактирование.
Предложение завершить появляется только при отметке занятия, закрывшей последнюю
тему; в редакторе показывается сообщение о полностью пройденном списке.
exhaustedAt, createdAt и updatedAt сохранены.

Room v5, миграция 4→5 и сохранённая цепочка 1→2→3→4→5.
Тест миграции проверяет сохранение курсов, категории, паузы, завершения, расписания,
ночного/равного времени, результатов занятий и прохождения тем; удаление архивированных
непройденных тем; частичный индекс и отсутствие нарушений внешних ключей.
Индекс отдельно проверен для новой файловой БД и освобождения цвета при завершении.
