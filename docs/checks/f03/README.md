# F03 — проверка и безопасная замена данных

Выполнено 2026-10-07. Реализован импорт без UI; выбор файла и подтверждение
полной замены остаются в F04.

## Реализация

- `BackupArchive` до любых изменений проверяет размер и состав ZIP, обязательные
  поля JSON, magic и major v1, обязательные возможности, UUID, SHA-256 и размер
  payload, ключи, ссылки и ограничения всех Room-сущностей.
- Репозиторий удаляет прежние строки в порядке зависимостей, вставляет весь новый
  снимок и фиксирует `committedBackupId` одной Room-транзакцией. Исключение на
  любой вставке откатывает и удаления, и вставки.
- Room v8 добавляет только внутреннюю таблицу `backup_state`; она не входит в
  копию. Версия схемы в manifest остаётся диагностикой: ZIP+JSON v1 от прежней
  схемы принимается по правилам формата.
- Перед транзакцией атомарно пишется внутренний PREPARED-журнал с `backupId`,
  SHA-256 payload и языком. После commit применяются язык, отмена alarm и активных
  уведомлений, очистка `reminders.delivered`, синхронизация календаря и
  `ReminderScheduler.reconcile()`.
- При следующем запуске журнал сравнивается с маркером Room. Несовпадение означает
  откат транзакции и удаляет журнал; совпадение идемпотентно завершает post-commit
  действия. Наблюдение напоминаний запускается после этой попытки восстановления.

## Проверки

Из `tracker-app/` с JDK 17:

```sh
./gradlew :app:assembleDebug :app:assembleDebugAndroidTest :app:testDebugUnitTest
./gradlew :app:lintDebug
```

Результат: обе сборки успешны, 33/33 JVM-теста прошли, lint — 0 ошибок.

На отдельном `ScheduleReturnFix` API 36 AVD без очистки выполнено повторяемое
заполнение 2/2, затем направленный набор:

```sh
adb shell am instrument -w \
  -e class com.utbildning.tracker.backup.BackupImportTest,com.utbildning.tracker.backup.BackupArchiveTest,com.utbildning.tracker.backup.BackupSnapshotTest,com.utbildning.tracker.data.local.TrackerMigrationTest \
  com.utbildning.tracker.test/androidx.test.runner.AndroidJUnitRunner
```

Результат: 16/16. Проверены полный круг со всеми переносимыми полями, повреждение
payload, неподдерживаемый major, потерянная ссылка, откат при исключении на вставке,
остановка после commit, два запуска recovery, повторная синхронизация без дублей,
очистка локальной дедупликации напоминаний, миграции 1/3/6→8 и восстановление v1
с прежним `databaseSchemaVersion`.

## Ограничения

- UI выбора файла, подтверждение и RU/EN тексты относятся к F04 и не начинались.
- Полный instrumentation-набор и Android 13 не запускались.
- На устройстве не моделировалось настоящее убийство процесса в точной точке
  после commit; обе стороны границы проверены управляемым исключением и новым
  экземпляром импортёра с тем же долговечным журналом.
