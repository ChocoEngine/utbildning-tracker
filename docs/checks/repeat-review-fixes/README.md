## Ограничения

На Android 13 не повторялось отдельное ночное RTC-ожидание 23:30→01:00/+90 минут и нажатие result-кнопки в шторке; эти пути фактически проверены на API 36, а обычная доставка, reboot, разрешения и полный instrumentation — на API 33. Кнопка `Skipped` проверена именно из системной шторки API 36 через UI-событие эмулятора, но не физическим пальцем; `Done` в шторке визуально присутствовала, а её системный `PendingIntent` ранее выполнен программно. R02 и R03 целиком не закрыты; R02-T01 (100 code points для темы) в эту работу не входил.
