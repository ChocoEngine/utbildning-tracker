# F12 — перезапуск завершённого курса

Проверено 2026-10-07 на отдельном `Medium_Phone_API_36` (Android 16 / API 36).

## Реализация

- В завершённом курсе доступно действие «Начать заново» с явным предупреждением:
  прохождение всех тем и все прежние занятия будут удалены безвозвратно.
- Подтверждение одной Room-транзакцией повторно выбирает первый свободный цвет
  в порядке 0–9, снимает завершение и паузу, сбрасывает прохождение тем, удаляет
  все занятия и расписание с правилами.
- Сохраняются ID, название, категория и дата создания курса, а также ID, названия
  и порядок тем. Расписание, занятия и напоминания не создаются.
- При десяти занятых цветах действие недоступно. Повторная проверка внутри
  транзакции защищает от устаревшего состояния UI; ошибка не оставляет частичных
  изменений. После успеха цвет можно поменять обычным способом.
- RU/EN предупреждение и гайд обновлены. Схема Room не менялась.

## Проверки

- `./gradlew :app:assembleDebug :app:testDebugUnitTest --console=plain` — успешно,
  33/33 JVM-теста.
- `./gradlew :app:lintDebug :app:assembleDebugAndroidTest --console=plain` — успешно,
  lint без ошибок; androidTest APK собран.
- `./gradlew :app:connectedDebugAndroidTest -Pandroid.testInstrumentationRunnerArguments.class=com.utbildning.tracker.data.CourseLifecycleRepositoryTest,com.utbildning.tracker.ui.CourseLifecycleScreenTest --console=plain`
  — 19/19 на API 36.
- После прогона повторяемое заполнение `scripts/seed-emulator.sh` прошло 2/2 и
  оставило AVD с тестовыми данными без очистки прежнего прогресса.

Направленные проверки покрывают сохранение метаданных и порядка тем, полный
сброс прогресса и истории, отсутствие расписания, выбор первого свободного цвета,
лимит десяти цветов, отмену, ошибку после уже начавшихся удалений с полным откатом,
повтор после ошибки, неизменность другого курса и повторное открытие редактора.

## Ограничения проверки

Полный instrumentation-набор, Android 13, физическое устройство и ручной
визуальный просмотр RU/EN не запускались. Создание системных уведомлений после
перезапуска исключено отсутствием расписания и занятий; отдельное реальное
ожидание alarm не выполнялось.
