# Переключение режима — 2026-09-26

По явному запросу пользователя реализовано включение расписания у существующего
курса без расписания и обратный переход с сохранением истории и прогресса.
Включение доступно кнопкой «Включить расписание» и выполняется атомарно при
сохранении дней/времени. Отмена оставляет прежний режим. Отключение — кнопкой
«Перейти без расписания» с подтверждением; нужен непустой список тем.
Удаляются только будущие PENDING (начало строго позже текущего момента).
Начавшиеся занятия и любые записанные результаты, связи с темами, прохождение,
цвет и категория сохраняются. Схема Room v2 не менялась.

Исправлен возврат после сохранения расписания: вызов навигации явно выполняется
на главном потоке. Сквозной тест до исправления подтверждал сохранение данных,
но выявлял IllegalStateException при возврате из формы.

## Проверки

Из `tracker-app/`, JDK 17, эмулятор Medium_Phone_API_36:

```sh
./gradlew :app:assembleDebug :app:lintDebug :app:testDebugUnitTest :app:connectedDebugAndroidTest '-Pandroid.testInstrumentationRunnerArguments.class=com.utbildning.tracker.data.ScheduleRepositoryTest,com.utbildning.tracker.ui.AppNavigationTest,com.utbildning.tracker.notifications.ReminderTest' --console=plain
```

Итог: BUILD SUCCESSFUL; 13 JVM-тестов и 15 инструментальных тестов,
без ошибок и пропусков. Проверены сохранность истории и прохождения,
повторная генерация без дублей, откат при ошибке/отсутствии тем,
запрет смены завершённого курса, отмена обеих форм, повторное включение
после пересоздания Activity, запрет доставки уведомлений после отключения.
`git diff --check` успешен.

Не выполнялись полный инструментальный набор, отдельная визуальная приёмка
RU/EN и Android 13. Реальная автоматическая отмена AlarmManager после нажатия
в UI отдельно не проверена: используется существующий наблюдатель
ReminderScheduler за изменениями курсов/занятий; тест проверяет запрет доставки.
Сброс прогресса, возобновление паузы и экспорт/импорт не реализованы в этом шаге.
F13/F14 остаются частичными относительно полного функционального плана.
