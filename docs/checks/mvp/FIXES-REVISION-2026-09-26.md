# Исправления по ревизии MVP — 2026-09-26

## Исправлено

- Для `UNSCHEDULED` скрыто действие «Пауза». Проверка допустимости операции в репозитории сохранена; пауза расписанного курса по-прежнему удаляет расписание и работает через прежний жизненный цикл.
- Календарная сетка рисует одно мягкое асимметричное пятно под числом и цветные полосы занятий поверх него. Пройденная полоса яркая, плановая и пропущенная бледные; крестик расположен внутри соответствующей полосы каждого пропуска. Используется палитра `design/mockups/PALETTE.md`.
- Семантическое описание календарного дня сохраняет перечисление статусов, а его потомки остаются отдельными семантическими узлами.
- Визуальная фикстура проверяет один день с пройденными, плановыми и несколькими пропущенными занятиями. Распределение тем по датам не добавлено.

Модель данных, расписание, прогресс, уведомления и зависимости не менялись. S25 и Android 13 не запускались.
