## Дефекты по важности

### Средняя: неработающая пауза у курса без расписания (S19)

- Файлы: `tracker-app/app/src/main/java/com/utbildning/tracker/ui/courses/CoursesScreen.kt:174`,
  `tracker-app/app/src/main/java/com/utbildning/tracker/data/TrackerOperations.kt:170`.
- Воспроизведение: создать курс «Без расписания» с темами → открыть редактор →
  «Пауза» → подтвердить.
- Фактически: UI предлагает действие для любого незавершённого неприостановленного
  курса; `pauseCourse` отвергает UNSCHEDULED с INVALID_SCHEDULE. Диалог остаётся
  с общей ошибкой сохранения, пауза не выполняется.
- Ожидается: доступность действия должна соответствовать поддерживаемому режиму.
  Пауза MVP снимает расписание; отдельного поведения для свободного курса нет.
- Подтверждение: детерминированный путь UI → ViewModel → репозиторий найден в коде.
  Отдельное ручное воспроизведение на устройстве не выполнялось.
  `CourseLifecycleScreenTest` проверяет паузу только у SCHEDULED.

## Непроверенное и ограничения

- Android 13 / API 33: запуска и проверок доставки нет; AVD API 33 отсутствует.
  Явное прежнее откладывание пользователем не отменялось этой ревизией.
- Скруглённая квадратная маска иконки на поддерживающем её launcher.
- Рендер автономных Preview в Android Studio; компиляция не равна рендеру.
- Повторные реальные reboot, смена часов/пояса, первый диалог разрешения,
  отзыв точного доступа и холодный запуск без сети в этой ревизии не выполнялись.
  Их свидетельства прочитаны в прежнем отчёте и не выдаются за новый прогон.
- Новое ручное прохождение всех экранов RU/EN, всех размеров и визуальная
  проверка каждого состояния не выполнялись. Существующие снимки и UI-тесты
  не доказывают все варианты отображения.
- Сохранение несохранённого черновика после уничтожения процесса не покрыто:
  CourseDraft хранится в ViewModel; имеющийся тест проверяет Activity.recreate.
  Это ограничение проверки, не заявленный дефект сохранённых данных MVP.
- Ошибки первоначального чтения расписания: LaunchedEffect в ScheduleScreen
  не перехватывает ошибку БД. Сбой хранилища не воспроизводился; это риск,
  отдельно от подтверждённых выше дефектов обычных сценариев.
- Критерий повседневного использования и работа на реальном устройстве
  разных производителей одним прогоном эмулятора не подтверждаются.

S25 и функции после MVP не ревизировались как обязательные критерии выпуска.
Новые функции и исправления не добавлялись.
