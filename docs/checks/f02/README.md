# F02 — ручной экспорт резервной копии

Проверено 2026-10-07. Реализован только F02; импорт и еженедельные копии не
начинались.

## Реализация

- В `backup/` добавлены модели снимка, детерминированная запись ZIP+JSON v1,
  SHA-256 и валидатор созданного контейнера.
- Все категории, курсы, темы, расписания, правила и занятия читаются в одной
  Room-транзакции. Язык читается до и после неё; при гонке снимок один раз
  повторяется, а повторная гонка завершает экспорт ошибкой.
- Готовый архив сначала создаётся и проверяется во внутреннем временном файле.
  Затем он пишется в документ из системного picker, повторно читается, сверяется
  побайтно по SHA-256 контейнера и ещё раз проходит валидатор.
- В настройках добавлена кнопка `Create backup` / `Создать копию` и отдельные
  состояния создания, успеха, отмены и ошибки. Гайд обновлён на русском и
  английском; явно указано, что файл не зашифрован.
- Экспорт не изменяет Room, настройки, уведомления или расписание.

## Проверки

Из `tracker-app/` с JDK 17:

```sh
./gradlew :app:assembleDebug :app:assembleDebugAndroidTest :app:testDebugUnitTest
./gradlew :app:lintDebug
```

Результат: сборка APK и androidTest успешна, 33/33 JVM-теста прошли, lint —
0 ошибок и 38 предупреждений.

На отдельном `ScheduleReturnFix` API 36 AVD без очистки выполнено повторяемое
заполнение (2/2 seed-теста), затем:

```sh
adb shell am instrument -w \
  -e class com.utbildning.tracker.backup.BackupArchiveTest,com.utbildning.tracker.backup.BackupSnapshotTest \
  com.utbildning.tracker.test/androidx.test.runner.AndroidJUnitRunner
```

Результат: 6/6. Проверены:

- полный состав: курс с темами и расписанием, курс без расписания, завершённый и
  приостановленный курсы, ручное и календарное прохождение тем, история всех
  результатов и язык;
- чтение готового контейнера тем же валидатором и сохранение каждого переносимого
  поля;
- согласованность снимка с параллельной Room-транзакцией;
- реальная запись через `MediaStore`, повторное открытие и неизменность рабочего
  снимка до и после экспорта;
- отказ доступа, сбой записи и несовпадение прочитанного результата.

В реальном системном picker на том же AVD отдельно проверены отмена с текстом
`Backup creation canceled` и успешное создание файла размером 20 553 байта с
текстом `Backup created`. Тестовый файл после проверки удалён; данные приложения
сохранены.

## Ограничения

- Полный instrumentation-набор, Android 13 и внешние облачные document provider
  не проверялись.
- Импорт, подтверждение замены, восстановление после сбоя и фоновые копии входят
  в F03–F05.
