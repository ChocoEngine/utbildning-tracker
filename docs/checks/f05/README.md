# F05 — еженедельная копия

Выполнено 2026-10-07.

## Реализация

- В настройках добавлены выбор постоянной SAF-папки, включение и выключение
  еженедельной копии, время последнего успеха и время последней ошибки.
- Папка хранится как URI этого устройства с постоянным разрешением. При смене
  папки старое разрешение освобождается после успешного получения нового.
- WorkManager регистрирует одну уникальную periodic-задачу с интервалом семь
  дней. Повторное включение и reconcile при запуске не создают параллельных
  заданий; выключение отменяет уникальную задачу.
- Каждый запуск создаёт новый файл с UTC-временем в имени. Прежние успешные
  файлы не открываются, не заменяются и автоматически не удаляются. При ошибке
  удаляется только новый незавершённый документ, если это разрешает провайдер.
- Ручной экспорт остался отдельным действием. Ручной и фоновый пути используют
  общий процессный mutex на всю операцию экспорта и проверки.
- Архив фоновой копии использует тот же формат и валидатор F01–F04; направленный
  тест восстановил из него исходный снимок после замены данных другим снимком.

## Фактические ограничения

- WorkManager не обещает точный день или час: первый запуск может произойти
  вскоре после включения, последующие могут задерживаться из-за системных
  фоновых ограничений. Провайдер сетевого хранилища может отдельно задерживать
  синхронизацию уже записанного файла.
- Удалённое разрешение и недоступность провайдера проверены программным сценарием;
  реальное отключение облачного провайдера через системный picker не выполнялось.
- Неполный новый документ удаляется по возможности провайдера; если провайдер
  откажет и в удалении, рядом может остаться незавершённый файл. Прежние успешные
  файлы при этом не изменяются.
- Полный instrumentation-набор и Android 13 не запускались.
