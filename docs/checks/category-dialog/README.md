# UI-C01 — категории и клавиатура

Проверено 2026-10-18 на отдельном AVD `ScheduleReturnFix`, Android API 36,
размер 840 × 1418 px при density 420 (примерно 320 × 540 dp). Debug APK
устанавливался поверх существующих данных; пользовательский AVD не изменялся.
Последнее уточнение добавления, выбора, подсветки и удаления проверено на том же
AVD после возврата физического размера 1080 × 2400 px при density 420; язык RU
оставлен системным по умолчанию. Узкая проверка предельных 20 символов сохранена.

## Результат

- В окне добавления курса введённый текст имени и категории использует
  `bodyLarge`, как текст подсказки поля.
- Новую категорию длиннее 20 Unicode code points нельзя ввести. Репозиторий
  независимо отклоняет создание или переименование более длинной категории.
  Ровно 20 emoji принимаются.
- «Добавить» создаёт категорию в списке, очищает поле и не выбирает новую строку
  автоматически. Текущая категория курса остаётся прежней до отдельного нажатия.
- Выбранная строка показывается без галочки и подсвечивается точно тем же цветом,
  что выбранные кнопки «Пройдено»/«Пропущено».
- Корзины возвращены в окно выбора категории редактора. Удаление требует
  подтверждения. Фраза «Курсы останутся без категории» показывается только если
  такие курсы есть; после удаления они действительно остаются без категории.
  Строка «Без категории» корзины не имеет. Отдельная UI-C02 для настроек отменена.
- В редакторе видны только название категории и карандаш. Окно карандаша
  показывает прокручиваемый список, «Без категории» и поле добавления новой.
  Выбор сохраняется сразу; новая категория появляется только по «Добавить» и
  затем выбирается как любая другая; отмена не записывает введённый текст.
- После пользовательской проверки категория в редакторе возвращена к обычному
  нежирному `bodyLarge`. Карандаш следует сразу за текстом с тем же промежутком,
  что карандаш после заголовка «Темы»; короткая категория больше не растягивает
  строку до правого края.
- При открытии клавиатуры список временно сворачивается. Поле, введённый текст,
  «Отмена» и «Добавить» видны над настоящим окном Gboard. После закрытия
  клавиатуры список снова доступен.
- Исправлена потеря фокуса поля новой категории: при появлении IME структура
  диалога больше не заменяется. Реальный клик сохраняет фокус, ввод с клавиатуры
  меняет значение и активирует «Добавить».
- Предельная категория из 20 широких символов отдельно проверена на 320 × 540 dp
  для RU (`Ш`) и EN (`W`). В редакторе и выбранной строке списка она полностью
  читается с переносом на две строки; карандаш и галочка не перекрываются. Поле
  ввода остаётся однострочным и прокручивается горизонтально, кнопки не закрыты
  клавиатурой.
