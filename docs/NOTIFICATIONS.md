# Уведомления MVP (S20–S21)

Перед реализацией проверены официальные документы Android:
[AlarmManager](https://developer.android.com/develop/background-work/services/alarms)
и [POST_NOTIFICATIONS](https://developer.android.com/develop/ui/compose/notifications/notification-permission).

Напоминание только в момент начала занятия. Используем `AlarmManager` с
`setExactAndAllowWhileIdle(RTC_WAKEUP)`, immutable PendingIntent и явным receiver.
Не используем периодический опрос вместо точной доставки. Одновременно
зарегистрирован один ближайший alarm; при его срабатывании показываются
напоминания всех актуальных занятий с этим началом и назначается следующий.
Это не превышает системный лимит количества alarm при большом календаре.

Для новых установок нужны runtime POST_NOTIFICATIONS и специальный доступ
SCHEDULE_EXACT_ALARM. Настройки приложения предлагают включить уведомления
и открыть системный экран точных напоминаний. При отказе календарь работает;
неточные напоминания не включаются скрыто. Состояние показано в настройках.
Даже с доступом доставка зависит от ограничений Android/производителя;
выключенное устройство и force-stop не позволяют гарантировать напоминание.
Без разрешения точных alarm уведомления не планируются.

При возврате приложения, изменении сессий/курсов, boot, смене времени/пояса
и выдаче доступа alarm выполняются догоняющая генерация и сверка. Receiver
перед показом перечитывает актуальное занятие/курс: PENDING, курс активен,
есть расписание, темы не исчерпаны; дата/время всё ещё совпадают с alarm.
Пропущенное из-за выключенного устройства напоминание не приходит позднее:
доставка допускается в пределах 5 минут после запланированного начала.
Уже показанные ID сохраняются локально для защиты от повторного broadcast.
Вопрос о результате не использует уведомлений.

Пауза/завершение/удаление/исчерпание/ранняя отметка результата пересчитывают
ближайший alarm и убирают уже показанные неактуальные уведомления. При
совпадающем времени занятий разные ID сохраняют отдельные уведомления.
Нажатие открывает экран выбранного занятия через explicit Activity intent.
Локаль следует настройке приложения; название курса не переводится.

## Проверка

Проверка Android 13 отложена пользователем. Пока нет её фактического результата,
S20 нельзя обозначать полностью проверенным на всех поддерживаемых версиях.
Результаты API 36, реальные доставка/отмена, reboot и ограничения записываются
в отчёте проверки; наличие кода receiver само по себе не доказывает доставку.
