Эти требования имеют приоритет над прежним редактором с общей кнопкой «Сохранить». Выполнять оставшиеся задачи по одной, сохранять прежние исправления ревизии. Не запускать S25 или функциональные расширения F01–F17.

## Согласованные правила

- На экране «Сегодня» убрать заголовок «Сегодня», сохранить дату и навигацию.
- «Добавить курс» в списке оформить заметной кнопкой. «Показать все» доступно только при наличии скрытых завершённых курсов. В раскрытом состоянии оставить обратное действие «Показать незавершённые», если оно изменит состав списка.
- Прогресс курса с темами показывать полосой цвета курса и числом пройденных тем. Название и полоса прогресса входят в один кликабельный блок, открывающий курс. Для курса без тем — число занятий без выдуманного процента.
- Цвета с пользовательскими номерами 1, 4, 7 должны быть визуально различимы. ID остаются стабильными; не менять резервирование, лимит или историческую принадлежность курса. Начатый вариант: №1 зелёный #78AC80, №4 голубой #6B9DCC, №7 тёмный бирюзовый #397F79. Перед завершением визуально проверить все десять вместе и синхронизировать PALETTE.md; в R05 все десять оттенков просмотрены вместе, новые оттенки различимы; PALETTE.md синхронизирован.
- Отметка темы не переставляет строки и не перенумеровывает остальные темы. Сохранять порядок списка, номер и отдельно отметку прохождения. Пройденные темы остаются защищёнными вне редактируемого текстового блока; это не причина переносить их наверх основного списка.
- «Завершить курс», «Поставить на паузу», «Удалить курс» — полноценные кнопки в едином стиле. По уточнению пользователя пауза доступна любому активному курсу, включая курс без расписания после продолжения; прежние подтверждения и бизнес-правила сохраняются.

## Создание курса

1. Кнопка добавления открывает небольшое окно с названием и категорией, действиями продолжения и отмены.
2. Название обязательно, не длиннее 50 символов; не обрезать незаметно. Валидация нужна в UI и операции сохранения, единое правило подсчёта Unicode-символов.
3. Продолжение открывает окно курса: вместо «Курсы» в шапке его название, кнопки настроек нет.
4. Актуальная модель v6 не содержит переключателя режима. Курс может иметь темы,
расписание, оба набора или ни одного; «Далее» сохраняет курс и открывает редактор.
5. Отмена первоначального окна не создаёт курс, категорию или резерв цвета.
Темы и расписание настраиваются независимо после создания.

## Редактирование и сохранение

- Название становится редактируемым полем после долгого нажатия. Сохранение при потере фокуса или выходе из окна; общего «Сохранить» нет.
- Категория всегда доступна как редактируемое поле с выпадающими подсказками. При пустом списке категорий не показывать пустое меню; отсутствие совпадений также не открывает пустой popup. Выбор существующей категории сохраняется сразу, ручной ввод — при потере фокуса (и при выходе с активным полем).
- Новая категория создаётся без дополнительного вопроса; совпадения без учёта регистра и крайних пробелов выбирают существующую. Изменение поля не переименовывает категорию остальных курсов. Удаление через корзину сохраняет прежние правила.
- Выбор цвета сохраняется сразу. Список тем сохраняется кнопкой «Применить», без последующего общего сохранения. «Отмена» текстового редактора отменяет только неприменённый текст; уже сохранённые поля не откатываются при выходе из курса.
- Долгое нажатие по теме сразу переключает прохождение; короткое нажатие и прокрутка не меняют отметку.
- До первичного создания курса перечисленные поля меняют черновик; после создания — сохраняются по указанным событиям.
- Быстрые изменения полей не должны теряться, перезаписывать соседнее поле устаревшим снимком или дублировать категории. Ошибка не маскируется успешным выходом: введённое значение остаётся доступным для исправления/повторного сохранения, база сохраняет последнее успешное значение.
- Проверить выход через кнопку назад, системный Back, нижнюю навигацию, открытие расписания и смену фокуса. Отдельно определить и проверить сохранение активного поля при уходе приложения в фон; не полагаться на случайный callback уничтожения Compose.
- Сохранение названия/категории/цвета не применяет неподтверждённый текст тем. Конфликт с пройденной темой блокирует только «Применить список», поскольку общей кнопки сохранения больше нет.

## Запланированное уточнение 2026-10-05 — R02-T01

Название темы при создании и применении списка после удаления крайних пробелов
обрезается до 100 Unicode code points. Во время ввода и вставки ограничение
не применяется; при сохранении лишнее обрезается без предупреждения. После
применения показываются сохранённые названия. Отмена не меняет данные,
пройденные темы остаются неизменными. Проверка конфликтов использует итоговые
названия. Это правило пока не реализовано; проверки — в POST_MVP_PLAN.md.
