# How to use

## Create a course

1. Open Courses → Add course.
2. Enter a name and, optionally, a category.
3. Tap Continue.

Topics and a schedule are optional — add them later if you wish.

## Add topics

1. In the course, tap the pencil next to Topics.
2. Type or paste your list, one topic per line.
3. Tap Apply list.

Reorder or remove unfinished topics in the editor. Completed topics stay in
the course; you cannot add them to the list again.

To mark a topic complete manually, press and hold it in the course.
Hold again to remove the mark. This does not create a calendar session.

## Set a schedule

1. In the course, tap the calendar icon.
2. Choose weekdays and start times. End times and an end date are optional.
3. Tap Save.

Tap the calendar again to change the schedule. History and progress are kept.
An end time earlier than the start means the session ends the next day.

## Record a session

1. Open Sessions and find the session under Today or Yesterday.
2. Tap Done.
3. If there are topics, select those you finished and confirm with Done.
   Leave them unselected if you studied but did not finish anything.

If you did not study, tap Skipped. Tapping the selected button again clears
the result. Undoing Done also clears the topic completion marks from that session.

You can change results only for today and yesterday, based on the session's
start date. Results in completed courses are read-only.

## View the calendar

Select a day in Calendar to see its sessions and results below.
Bright marks mean Done; pale marks mean Planned or Skipped.
Change results in Sessions.

Unmarked sessions from past days become Skipped.
You can still correct yesterday's results.

## Enable reminders

In Settings (the gear icon), allow notifications and, if Android requests it,
access to alarms and reminders.

Reminders arrive at the start of a session and ask about the result at its end,
or 90 minutes after the start if no end time is set.
Tap the notification to open the session. The tracker also works without permissions.

## Take a break or complete a course

- **Pause** in the course keeps history and progress, removes the schedule and
  future sessions without a result. Confirm the action.
- **Resume** ends the pause. Set the schedule again using the calendar icon.
- **Complete**, after confirmation, marks remaining topics and started sessions
  without a result complete, removes future sessions and makes the course read-only.

After the session that completes the final topic, the app offers to complete
the course. You can keep it active and add new topics later.

## Start again or delete

To repeat a completed course, open Courses → Show all,
select the course → Start again.

> Back up before confirming: all topic progress and previous sessions for this
> course are permanently deleted. The name, category and topic list are kept.
> Set the schedule again.

To delete a course, tap Delete in the course and confirm.

> The course, its topics and session history are deleted. This cannot be undone.

## Save a backup

1. Open Settings → Backup → Create backup.
2. Choose where to save the file.
3. Wait for Backup created.

The backup contains courses, categories, topics, schedules, history and language.
Back up before deleting or restarting a course, shortening history or moving
to another phone. Keep an older known-good copy too.

> Backup files are not encrypted. Keep them private.

## Restore your data

1. Open Settings → Restore backup → Choose backup.
2. Select a file and wait for it to be checked.
3. Tap Replace and restore.

> All current data is replaced with the backup's contents. You cannot merge them.
> Save current data as a separate backup first if you need it.

Canceling or choosing an invalid file leaves current data unchanged.
On another phone, choose the weekly backup folder again and check notification
permissions.

## Enable weekly backups

In Settings → Weekly backup, tap Choose folder, allow access and turn on
the switch. Check the last successful backup date and any errors here.

Backups are created about once a week when storage is available.
Android does not guarantee an exact time. Older successful files are not deleted
automatically.

## Choose how long to keep history

Open Settings → Calendar history → Set retention. By default, the app keeps
today and the previous 365 days. Choose 1–3650 previous days, or turn off
Remove old sessions to keep everything.

> Cleanup removes older sessions from every course. The day at the retention
> boundary is kept, as are topics and topic progress. Back up any history you need
> before shortening retention or turning cleanup on.

Shortening history requires confirmation. Cleanup runs in the background about
once a day; the exact time is not guaranteed.

## Good to know

- You can have up to 10 unfinished courses, including paused ones. Adding or
  restarting a course needs a free color; completing a course frees its color.
- The trash icon in the category list deletes the category while keeping its
  courses. Canceling the course form does not undo this deletion.
