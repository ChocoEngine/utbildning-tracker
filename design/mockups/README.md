## Сценарии

Создание: название и необязательная категория → «Далее» сохраняет курс, без
выбора режима. Темы и расписание задаются независимо. Общего «Сохранить» курса
нет. Название редактируется удержанием и сохраняется при потере фокуса/выходе;
категория — выбором, потерей фокуса или закрытием окна; цвет — сразу.
Неприменённый список тем не сохраняется вместе с полями: «Применить список»
либо «Отмена». При применении trim и первые 100 Unicode code points каждой темы,
конфликт с пройденной темой блокирует применение. Номера и порядок при отметке
не меняются; в редакторе действует удержание, на занятии — обычный выбор.

Цвет — отдельное окно; категория компактна. Расписание над темами, действия
курса закреплены. На паузе расписание скрыто; продолжение сохраняет прогресс
и цвет, расписание настраивается отдельно. Пауза доступна снова без расписания.
Завершение оставляет экран открытым; цвет освобождается, редактирование блокируется.
Ручная отметка всех тем не предлагает завершение; предложение появляется только
после результата занятия, закрывшего последнюю тему.

В courses прокручиваются строки; шапка, добавление, сводка и навигация закреплены.
У курсов без тем нет счётчика занятий/процента. Расписание показывается у всех
курсов, у которых оно задано. Пауза сохраняет цвет, завершённые имеют галочку.
В today независимые списки сегодня/вчера, два результата и снятие выбранного.
Календарь показывает курсы, не распределённые темы, и не меняет результат.

Конец необязателен; раньше начала означает следующие сутки, равные времена —
ноль минут. «Добавить конец» открывает выбор, отмена не задаёт конец; крестик
его убирает. Можно сохранить одну конечную дату или пустую форму.
Пересечения — мягкое предупреждение «В то же время:», сохранение разрешено.
Без конца для пересечений используется час до полуночи; вопрос о результате
в приложении остаётся через 90 минут. [Палитра](PALETTE.md) соответствует Color.kt.

## Локальная демонстрация

Данные и изменения каждого файла изолированы. Встроенный редактор courses
показывает поля и независимые упрощённые окна тем/расписания; полный редактор
course-editor имеет собственную фикстуру.
Нижняя навигация — оформление, а не общая навигационная модель.
Receipt результата — локальная обратная связь, в приложении происходит возврат.
Временной пример фиксирован (26/25 сентября); работающий таймер не моделируется.
Room, Android IME/lifecycle, системные уведомления, ошибки долговечной записи,
DST и полная фильтрация пересечений по датам не моделируются.
Макеты только RU, EN отсутствует. Тёмные варианты остаются демонстрационными.

## Исходники и экспорт

Править `sources/*.html`, затем экспортировать соответствующий документ
штатным `scripts/render.py` навыка visualize. Сгенерированные документы вручную
не редактировать. Экспорт содержит sandboxed iframe; CDN обёртки требуют сети,
включая иконки. Макеты сохранены в проекте и не зависят от кеша чата.

```sh
python3 /path/to/visualize/scripts/render.py "$PWD/design/mockups/sources/courses.html" "$PWD/design/mockups/courses.html" --force
```

Текущие экспорты получены visualize 1.0.47. При переходе на другую версию навыка
повторно проверять обёртку и все взаимодействия в браузере.
