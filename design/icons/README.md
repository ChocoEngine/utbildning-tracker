# Иконка приложения

Актуальный векторный исходник — [ink-launcher.svg](ink-launcher.svg).
Три цветные диагональные полосы внутри мягкого асимметричного пятна на светлом
фоне. Цвета: `#78AC80`, `#DC9475`, `#9D95CC`; фон `#FCFAF6`.

Android использует отдельные VectorDrawable переднего плана и монохромного
силуэта, фон и adaptive icon в `tracker-app/app/src/main/res/`.
Результат прежней проверки установленной иконки кратко записан в
[сводке](../../docs/VERIFICATION_BASELINE.md); исходным продуктовым ориентиром служит текущий ресурс
приложения, а не прежний лист концептов.
